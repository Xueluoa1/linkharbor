# 拾链 v1.0.3 · 正式版

发布日期 2026-11-27

## 下载

- [Windows 安装包 EXE](https://github.com/Xueluoa1/linkharbor/releases/download/v1.0.3/LinkHarbor-v1.0.3-Setup.exe)。双击选择安装目录，再点击“安装”。
- [ZIP 便携包](https://github.com/Xueluoa1/linkharbor/releases/download/v1.0.3/LinkHarbor-v1.0.3-Windows-x64.zip)。完整解压后运行 `拾链下载器.exe`，保留 `tools/` 文件夹。
- [源码 ZIP](https://github.com/Xueluoa1/linkharbor/releases/download/v1.0.3/LinkHarbor-v1.0.3-Source.zip)。包含应用、安装器、测试和构建脚本。

安装包和便携包适用于 Windows 10/11 x64，随包提供 yt-dlp、FFmpeg 和 Node.js。抖音和小红书的网页解析以及网页登录需要系统已安装 Microsoft Edge 或 Google Chrome。

## 本次更新

- 可直接粘贴抖音、小红书和 B 站的整段分享文案。小红书分享参数和 B 站分 P 参数会随链接保留。
- 抖音和小红书新增网页解析。B 站分 P 兼容返回的媒体条目，每条链接处理一个作品或分 P。
- “网络与登录”新增网页登录授权。选择站点，在拾链打开的浏览器里登录，关掉窗口后再解析。
- 可拖入 Netscape 格式的 Cookie 文件。拾链会记住文件路径，点击“清除”即可解除绑定。开启“国内网站直连”时，抖音、小红书和 B 站绕过应用内配置的代理。

安装版可使用原安装目录覆盖升级。安装与卸载保留个人设置和下载文件。站点能否解析和下载仍取决于网站、网络及账号权限。
