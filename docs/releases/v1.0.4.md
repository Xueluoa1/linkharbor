# 拾链 v1.0.4

2026-11-27

## 下载

- [Windows 安装包 EXE](https://github.com/Xueluoa1/linkharbor/releases/download/v1.0.4/LinkHarbor-v1.0.4-Setup.exe)。双击后选择安装目录，点击“安装”。
- [便携 ZIP](https://github.com/Xueluoa1/linkharbor/releases/download/v1.0.4/LinkHarbor-v1.0.4-Windows-x64.zip)。完整解压后运行 `拾链下载器.exe`，保留 `tools/` 文件夹。
- [源码 ZIP](https://github.com/Xueluoa1/linkharbor/releases/download/v1.0.4/LinkHarbor-v1.0.4-Source.zip)。包含程序、安装器、测试和构建脚本。

适用于 Windows 10/11 x64。网页登录需要系统安装 Chrome 或 Edge。

## B 站网页登录

打开“网络与登录 → 网页登录授权 → 哔哩哔哩”，在拾链打开的 Chrome 或 Edge 窗口中完成登录，再关闭窗口。看到“已保存 B 站 Cookie”后，即可粘贴 bilibili.com 视频链接或 b23.tv 短链。已手动绑定 Cookie 文件的用户可继续沿用该文件，点击“清除”后改用网页登录授权。

拾链使用刚才登录的浏览器导出 B 站仍有效的 Cookie。授权文件保存在拾链浏览器配置目录中的 `bilibili-cookies.txt`。每个解析或下载任务使用独立副本。授权文件包含登录凭据，请勿分享。

## 画质和网页解析

- 设置 720p 等画质上限时，带高度信息的视频流仍受上限约束。小红书回退视频和部分直链缺少高度信息时也可以参与选择，实际分辨率取决于源文件。
- 抖音和小红书的网页解析使用当前浏览器版本对应的 UA 和中文语言偏好。下载请求沿用解析时的 UA。
- 主窗口宽度变化时，Cookie 绑定状态与国内直连选项各占一行。

## 从 v1.0.3 升级

安装版使用 `%LOCALAPPDATA%\LinkHarbor\browser-profile` 保存浏览器配置。使用过网页登录的用户需在新位置重新授权一次。便携版继续使用程序旁的 `data\browser-profile`，B 站使用独立的子目录，首次使用请重新授权。

安装版可使用原安装目录覆盖升级。设置和下载文件会保留。

从源码构建可运行 `.\build.ps1`。双击根目录的 `拾链下载器.exe` 启动，并保留同目录配套的 `tools` 文件夹。[操作教程](https://github.com/Xueluoa1/linkharbor/blob/v1.0.4/docs/使用教程.md)
