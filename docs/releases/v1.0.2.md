# 拾链 v1.0.2 · 正式版

发布日期：2026-11-23

## 下载

- **[直接下载安装包 EXE](https://github.com/Xueluoa1/linkharbor/releases/download/v1.0.2/LinkHarbor-v1.0.2-Setup.exe)**：选择安装位置和桌面快捷方式，点击安装后显示实际进度，完成后启动。
- [ZIP 便携包](https://github.com/Xueluoa1/linkharbor/releases/download/v1.0.2/LinkHarbor-v1.0.2-Windows-x64.zip)：完整解压后运行 `拾链下载器.exe`，保留 `tools/`。
- [完整源码 ZIP](https://github.com/Xueluoa1/linkharbor/releases/download/v1.0.2/LinkHarbor-v1.0.2-Source.zip)：包含应用、安装器、测试与构建脚本；运行组件按 `tools/README.md` 准备。

支持 Windows 10/11 x64，需要 .NET Framework 4.x。安装包与便携包包含 yt-dlp、FFmpeg、Node.js，无需另行安装组件。GitHub 自动生成的 Source code 是源码，不能直接运行。发布附件仅提供安装 EXE 和压缩包，SHA-256 校验值列于发布页。

## 本次更新

- 视频编码可选原始编码、H.264 / MP4、H.265 / MP4、AV1 / MP4 转码。
- 新增 MP4 快速封装，保留源 H.264 和 AAC，不重新压缩；新增 AV1 原生流直下，缺少匹配格式时提示手动转码。
- 仅音频新增 AAC / M4A，优先提取源 AAC 音轨，其他音轨转为 AAC。
- 转码另存并保留原文件；批量总进度包含转码和校验，取消时清理未完成的转码文件。
- 已有转换结果先校验再复用，不覆盖无效同名文件；HDR 内容提示保留原始编码。

软件转码耗时且有损，播放器对 H.265、AV1 的支持不同；希望保留源画质时使用原始编码或符合源格式的快速封装。下载效果仍受站点、网络与账号权限影响。

## 升级与卸载

安装版升级前退出拾链，运行新版安装包并使用原安装目录。设置位于 `%LOCALAPPDATA%\LinkHarbor\settings.json`，默认下载位于用户“视频/拾链”；升级和卸载保留个人设置与下载文件。便携版建议解压到新目录，再迁移需要的设置和下载内容。
