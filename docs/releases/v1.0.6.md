# 拾链 v1.0.6 · 正式版

发布日期 2026-11-28

## 下载

- [Windows 安装包 EXE](https://github.com/Xueluoa1/linkharbor/releases/download/v1.0.6/LinkHarbor-v1.0.6-Setup.exe)。双击选择安装目录，点击“安装”。
- [便携 ZIP](https://github.com/Xueluoa1/linkharbor/releases/download/v1.0.6/LinkHarbor-v1.0.6-Windows-x64.zip)。完整解压后运行 `拾链下载器.exe`，保留 `tools/` 文件夹。
- [源码 ZIP](https://github.com/Xueluoa1/linkharbor/releases/download/v1.0.6/LinkHarbor-v1.0.6-Source.zip)。包含程序、安装器、测试和构建脚本。

支持 Windows 10/11 x64。安装版可在原目录覆盖升级，保留个人设置和下载文件。

## 本次更新

- 在“网络与登录”多选或拖入多个 Netscape 格式的 Cookie 文件。混合站点批量解析和下载时，每条链接自动使用对应站点的 Cookie。同一站点优先使用最近添加且含未过期条目的文件。
- 点击“管理 Cookie”可查看已绑定的文件、完整路径、网站和过期提示，也可移除单个绑定或清除全部。v1.0.5 中绑定的单个文件在升级后会自动恢复。
- 调整工作台和网络设置布局，适配窄窗口和较宽窗口。点击左侧网络入口后可直接填写代理地址。
