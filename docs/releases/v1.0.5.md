# 拾链 v1.0.5 · 正式版

发布日期 2026-11-27

## 下载

- [Windows 安装包 EXE](https://github.com/Xueluoa1/linkharbor/releases/download/v1.0.5/LinkHarbor-v1.0.5-Setup.exe)。双击选择安装目录，点击“安装”。
- [便携 ZIP](https://github.com/Xueluoa1/linkharbor/releases/download/v1.0.5/LinkHarbor-v1.0.5-Windows-x64.zip)。完整解压后运行 `拾链下载器.exe`，保留 `tools/` 文件夹。
- [源码 ZIP](https://github.com/Xueluoa1/linkharbor/releases/download/v1.0.5/LinkHarbor-v1.0.5-Source.zip)。包含程序、安装器和构建脚本。

支持 Windows 10/11 x64。安装版可在原目录覆盖升级，保留个人设置和下载文件。

## 本次更新

- 任务日志窗口根据内容和屏幕空间调整大小，长行自动换行，打开时从顶部显示。
- 任务详情将不同日志条目分隔，便于定位错误和查看处理步骤。
- 新下载使用较短的文件名，降低长标题造成保存路径超限的概率。
