下载 **LinkHarbor-v1.0.1-Windows-x64.zip**，完整解压后双击 **拾链下载器.exe**；保留同目录 `tools/`，不需要另装 Python 或 Node.js。系统要求 Windows 10/11 x64 与 .NET Framework 4.x。

**不要将 GitHub 自动生成的 Source code 当作便携程序下载。**
