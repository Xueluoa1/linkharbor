# 拾链 v1.0.1 安装包

安装界面使用 C# WinForms，与主程序共用 `src/Theme.cs` 的渐变、按钮和进度条。`packaging/Setup.cs` 负责选择路径、显示状态、启动程序；内嵌 `packaging/installer.iss` 构建的 Inno Setup 引擎，负责文件安装、当前用户快捷方式、卸载登记和取消回滚。运行时无需网络。

## 准备与构建

1. 使用 Windows 10/11 x64、PowerShell 和系统 .NET Framework 编译器，检出仓库 `master`，或解压 Release 的 `LinkHarbor-v1.0.1-Setup-Source.zip`。
2. 按 `tools/README.md` 准备完整依赖，运行 `check-tools.ps1 -VerifyHashes`。
3. 从 [Inno Setup 官方 6.7.3 发布页](https://github.com/jrsoftware/issrc/releases/tag/is-6_7_3) 获取编译器并验证签名。此项目使用的 `innosetup-6.7.3.exe` SHA-256 为 `9c73c3bae7ed48d44112a0f48e66742c00090bdb5bef71d9d3c056c66e97b732`。将编译器放在 `build/inno/`，或通过参数指定路径；不要提交编译器二进制。自行使用第三方构建工具时遵守其适用条款。
4. 执行：

```powershell
.\package-installer.ps1 -InnoCompiler 'C:\Path\To\Inno Setup 6\ISCC.exe'
```

产物为 `dist/LinkHarbor-v1.0.1-Setup.exe` 和对应 `.exe.sha256.txt`。脚本只从便携打包白名单收集文件，再加入 `installed-mode` 标记和 Inno Setup 许可证，不包含个人设置、Cookie 或下载内容。LZMA2 压缩时需较多内存，耗时视机器而定。运行组件原样保留。

## 验证

```powershell
.\test.ps1
.\test-batch.ps1
.\test-ui.ps1
# 将下面路径替换为 package-installer.ps1 最后输出的实际工作目录
.\test-installer.ps1 -Backend 'E:\project\build\installer-实际ID\LinkHarbor-Backend.exe'
```

安装器测试需要桌面会话，会真实安装到随机 `test-output/installer-*` 目录，创建当前用户快捷方式和卸载登记，然后卸载。检测到当前用户已有拾链安装/快捷方式时直接停止，避免覆盖用户安装；建议使用独立 Windows 测试用户。验证中文/空格路径、选项被进度替换、真实中间进度、取消回滚、桌面选项、开始菜单、重复安装、主程序启动、卸载及用户文件保留。测试失败时查看输出目录；若已完成安装，可运行该测试目录内的 `unins000.exe` 清理。

界面截图诊断：`Setup.exe /SCREENSHOT="C:\temp\ready.png"`；输出路径文件名含 `progress` 时生成进度状态截图，不会安装。截图目录须已存在。

自动安装参数：`Setup.exe /DIR="D:\Apps\LinkHarbor" /NODESKTOP`，会显示进度并完成后退出，退出码 0 表示成功。省略 `/NODESKTOP` 时创建桌面快捷方式。此入口与界面按钮使用相同的路径验证和安装流程。

## 数据与升级边界

- 默认当前用户安装到 `%LOCALAPPDATA%\Programs\LinkHarbor`，不要求管理员权限；自选路径需要写权限。不能选磁盘根目录、网络路径或包含其他内容的非拾链目录。
- 仅当主程序旁存在 `installed-mode` 时使用安装版路径：设置为 `%LOCALAPPDATA%\LinkHarbor\settings.json`，默认下载为 Windows 用户视频目录中的“拾链”。没有标记的便携版继续在程序旁保存数据。
- 同一 AppId 在原目录覆盖升级。更换目录前先卸载；旧便携设置由用户按教程手动迁移，安装器不扫描个人目录。
- 卸载只移除安装器管理的文件与快捷方式，不使用通配递归删除用户目录，不清除设置或媒体。
- 安装引擎以 `CurInstallProgressChanged` 报告真实进度。前端最多显示 99%，引擎成功退出才显示 100%。取消通过临时信号请求引擎的标准回滚，结束前保持窗口打开。
- 本安装包尚未配置商业代码签名证书；SHA-256 用于核验文件。应用版本及历史更新说明保持 v1.0.1。
