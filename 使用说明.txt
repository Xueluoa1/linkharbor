拾链 v1.0.1 · 正式版 · 视频解析下载
===================

开始使用
1. 双击同一目录中的“拾链下载器.exe”。无需安装 Python 或 Node.js。
2. 输入一个或多个视频页面链接，以回车换行、英文 ; 或中文 ； 分隔。
   回车只换行，必须点击“解析链接”才开始解析；重复链接自动忽略。
3. 选择“视频 + 音频”“仅音频 · 原格式”或“仅音频 · MP3”。
4. 视频可选择最佳可用画质或清晰度上限。
5. 点击“开始下载”，最多同时下载 3 项，其余自动排队。设置统一应用于本批次。
6. 点击左侧下载图标，查看每项任务的状态、进度、速度、剩余时间、文件路径和日志。
   关闭任务弹窗不影响下载；完成后点击“打开文件夹”查看文件。

安装版默认保存到用户“视频/拾链”，便携版保存在工具旁的“下载”文件夹，可点击“更改位置”。
移动到其他电脑时，请复制整个文件夹，保留 tools 文件夹。
适用于 Windows 10/11 64 位，需要系统内置的 .NET Framework 4.x。

新版界面

- 链接输入框右侧为“清除”按钮，清空链接与解析状态；粘贴链接使用 Ctrl+V。
- 浅色渐变背景、圆角卡片、蓝色主要操作与左侧图标导航。
- 已移除重复的横向导航按钮行；工作台、网络设置、日志均从左侧圆形按钮进入。
- 圆角按钮显式重绘底层背景，修复四角残字、色块及黑边。
- 顶部流程提示对应“粘贴链接 → 解析内容 → 保存到本地”。
- 左侧依次为工作台、当前任务、下载文件夹、网络设置、任务日志，底部为帮助。
- 网络与登录卡片直接显示代理和 Cookie 入口，点击“如何获取？”查看“代理地址与端口”“Cookie 文件”和“浏览器插件”三页说明。
- 左下角“注意”包含常见支持平台、使用限制和官方完整列表入口。
- 帮助页包含 HTTP / Mixed 本地端口查找、Windows 手动代理设置、SOCKS5 填写方法。
- 默认窗口高度已收紧，减少底部留白。
- 窗口缩窄后自动切为单列；可以滚动，也可以通过侧栏跳到对应区域。
- 拖动顶部空白区域移动窗口；右上角可最小化、最大化和关闭，边缘可调整大小。

文件格式与任务
- 分离的视频和音频自动合并为 MKV，以兼容不同视频编码；单文件来源保留原格式。
- 原格式音频尽量保留原编码；MP3 需要转换，可能耗时且会再次压缩。
- 主界面显示所有任务进度的平均估算，包含视频、音频、合并和最终文件保存。
  任务弹窗显示每项任务进度和当前媒体流大小；切换媒体流时任务总进度不会回退。
  单条失败不会中断其他任务，失败或取消不计为完成；全部成功后总进度才为 100%。
- 显示“正在合并 / 转换”时，请等待最终文件写入完成。
- 已有同名完整文件自动跳过。取消后保留临时文件，重试相同内容时可尝试续传。
- 点击“取消全部”会停止运行中及排队中的任务，并停止 FFmpeg 等子进程；已完成文件保留。
- 批量文件名包含链接短标识，避免相同标题或编号的任务同时写入同一个文件。
- 支持多个单视频链接，不处理频道、播放列表或进行中的直播。

网络与登录
- 若无法连接视频网站，点击左侧地球图标，定位到“网络与登录”设置卡片，填写你实际使用的代理地址。
  示例：http://127.0.0.1:7890（端口应以你的代理软件设置为准）。
- 如果网站要求登录或提示“确认不是机器人”，可以选择自己导出的 Netscape 格式 cookies.txt。
  Cookie 文件仅用于当前会话，不会自动读取浏览器登录信息；不需要时点击“清除”。
  Cookie 属于登录凭证，请勿分享。每个解析/下载进程使用独立临时副本，用后清理；原文件不变。
  一批任务共用所选 Cookie 来源；不同网站都需要登录时，可分批下载并切换对应的 Cookie 文件。
- Cookie 或代理并不保证所有视频可下载，结果仍受网站验证、账号权限和网络影响。
- “任务日志”提供具体错误信息。关闭工具会清空内存中的任务日志。
- 普通代理地址和保存位置会写入 settings.json；带账号密码的代理地址不保存。

支持平台与 Cookie 插件
- 常见支持平台：B站、AcFun、优酷、爱奇艺、抖音、小红书、微博、TikTok、
  YouTube（含 Shorts）、Vimeo、Dailymotion、Niconico、X / Twitter、Facebook、
  Instagram、Reddit，以及 Twitch 回放与片段。
- 以上平台已有解析支持，未逐一实测；具体以链接解析结果为准。
  官方完整列表：https://github.com/yt-dlp/yt-dlp/blob/master/supportedsites.md
- 打开视频网站并登录，进入目标视频页面，再导出当前网站的 Netscape 格式 Cookie。
  换网站时选用对应网站的 Cookie；失效后重新登录并导出。
- Chrome：Get cookies.txt LOCALLY（kairi003），选择 Netscape → Export。
  Microsoft Edge：在 Edge 中打开同一商店页面，按提示允许其他商店的扩展。
  https://chromewebstore.google.com/detail/get-cookiestxt-locally/cclelndahbckbenkjhflpdbgdldlbecc
- Firefox：cookies.txt（Lennon Hill），从 Firefox 附加组件商店安装。
  https://addons.mozilla.org/en-US/firefox/addon/cookies-txt/
- 其他支持 Chrome 扩展的浏览器可尝试 Chrome 插件，兼容性以浏览器为准。
- 插件入口由系统默认浏览器打开；可将商店地址复制到需要安装插件的浏览器。
  Edge 安装说明：https://support.microsoft.com/en-us/edge/add-turn-off-or-remove-extensions-in-microsoft-edge
